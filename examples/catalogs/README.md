# Версии оцифрованных каталогов

Эти каталоги публичны; владелец разрешил публиковать JSON. Версии сохраняются отдельными снимками. Размер, SHA-256, версия программы, Git revision и статус указаны в [manifest.json](manifest.json) и внутри файлов.

| Снимок | Что сохранено | Статус |
|---|---|---|
| [ОПН и малый каталог, завершённые снимки14October](reviewed-2026-10-14-v1.5.8) | JSON и Excel:60/60 и228/228 страниц; версии/источники/страницы в JSON и листе «Происхождение» | **Приняты native проверкой**. Сборка1.5.8; фактические исторические producers сохранены, нового процента точности нет |
| [Прямое извлечение всех пяти каталогов](2026-10-12-native-prototype) | 980 физических страниц: исходный текст, AnyDoc hints и доступные структурированные данные. Файлы 0,37–1,85 МБ | **Непроверенный черновик**. Producer: catalog-to-json 1.3.0 с изменениями, parent `470614c`, source SHA `eb3a1664…ff4d`; это прототип будущего native-batch, не неизменённый релиз 1.3.0 |
| [ОПН, промежуточный снимок](2026-10-12-catalog-to-json-1.4.0-checkpoint/opn.json) | 11 извлечённых страниц; 4 приняли свежую проверку, остальные сохраняют свой статус | **Каталог не завершён**. Producer: catalog-to-json 1.4.0, clean Git `0dc37f8`, MiniMax M3.1 Flash Preview → GLM 5.3 Flash |

`native_source_text` сохраняет прямо извлечённый PDF-текст без исправления, `anydoc_markdown_hint` — подсказку парсера. Пустой текст скана, `content: null`, неизвестные ячейки и ошибки остаются видимыми. Это не доказательство полного распознавания таблиц или рисунков.

Порог размещения одного JSON в Git — 10 МиБ. Более крупные снимки размещаются на Яндекс.Диске; в Git остаются ссылка, версия программы, источник, хеш, размер и статус проверки. Сейчас все опубликованные JSON меньше порога, поэтому внешнее хранилище им не требуется. Исходные PDF, учётные данные и переписка моделей в эти снимки не входят.
