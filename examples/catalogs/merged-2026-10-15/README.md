# Сведённые каталоги Никиты и Олега — 15 октября 2026

[Скачать один итоговый ZIP, 98 МБ](https://yadi.sk/d/vG15arblr9saTQ).

Все 980 физических страниц пяти PDF сведены в один набор. В архиве:

- `catalogue.json`: выбранные данные, точные исходные факты обеих сторон, архив альтернатив и решения по каждой странице.
- Пять Excel: `opn.xlsx`, `isolators.xlsx`, `small.xlsx`, `innovations.xlsx`, `armature.xlsx`. В каждой книге есть первичные данные, решения сведения и исправления до/после.
- `corrections.json`, `reconciliation-report.json`, `manifest.json` и оба исходных ZIP в `originals/` без изменений.

Сохранены 195 880 типизированных исходных фактов и 84 044 группы решений. 42 факта оставлены с явной пометкой неопределённости. 113 исправлений канонических ячеек/шапок — отдельный показатель: он не включает случаи отклонения альтернативы Олега без изменения нашей ячейки. Полный журнал есть в JSON и на листах «Решения сведения».

Это завершённое сведение, а не новый процент точности. Независимая итоговая проверка отложена по решению владельца. Варианты не извлекались заново ради сведения; исходные числа, марки, единицы, условия, авторы/модели/версии и страницы сохранены.

Ядро программы: 1.5.26. Архив создал сборщик `3191c42`, потоковую проверку выполнил `7187d46`; фактический производитель каждого извлечения и решения записан отдельно. Проверены ZIP CRC, SHA всех членов, оба исходных ZIP и все 118 437 строк первичных данных/неопределённостей плюс 84 044 строки решений Excel против JSON. Файл повторно скачан по публичной ссылке: SHA совпал. Проверки не вызывали модели.

Контрольная сумма и компактный отчёт находятся рядом: `SHA256SUMS.txt`, `delivery-manifest.json`.
