# Проверка свидетельств для чертежей 1.4.29

Проверяющий получает два новых инструмента: inventory потенциальных размерных подписей и запись связи подписи с видимым контуром. Запись связывается с SHA кандидата, физической страницей и исходным PDF; содержит отдельный вид/исполнение, точную цитату проверяемого описания, область оригинала, наконечники, контур и заключение о совпадении.

Числовая подпись не исчезает из обязательного инвентаря при переименовании фигуры или добавлении текста. Даты и идентификаторы допускают отдельную классификацию annotation по просмотренному источнику; диаметры и допуски не могут использовать эту классификацию. Для линейных/диаметральных размерных линий требуются два разных наконечника, для выносок может быть один. Нативные точки сверяются с выбранными paths; сканы допускают Vision. Исправление записанного вывода требует причины; прежняя версия, включая отрицательный вывод, остаётся в истории.

Общий figures PASS запрещён без покрытия этих подписей, в том числе в отчёте REVISE, который замечает только пунктуацию. Недоказанную или ошибочную связь надо явно отклонить. Таблицы и текст кандидата инструмент не изменяет.

На трёх сохранённых ложных PASS страниц 27/39 новый save_review отказался подтверждать чертежи без свидетельств. [Входные SHA и результаты](../examples/dimension-review/v1.4.29/retained-replay.json). Эти повторы не вызывали моделей.

Это контроль полноты свидетельств, не автоматическое доказательство геометрической истины. Модель всё ещё может ошибиться в выборе контура или назвать размер выноской. Увеличение точности в процентах не установлено. До подключения к полной очереди нужен ограниченный настоящий осмотр известной ошибки; общий бенчмарк не перезапускается. Старые принятые страницы сохраняют прежние версии и ограничения своей проверки.
