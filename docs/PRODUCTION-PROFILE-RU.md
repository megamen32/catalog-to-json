# Рабочая связка для завершения всех каталогов

Извлекатель — MiniMax-M3.1-Flash-Preview с программой1.4.15; проверяющий — GLM5.3Flash через Coding Endpoint с программой1.4.21. Управляющая очередь использует1.4.25 для подтверждённых исправлений сохранения состояния. Версия управляющего процесса не заменяет версии создавших JSON и review агентов.

Извлекатель15 сохраняется как испытанный профиль. Проверяющий21 включает независимую запись исходной страницы перед раскрытием кандидата и исправление ложных различий единиц измерения. Существующий настоящий blind-прогон страницы27 проверил180ячеек и устранил прежние ложные unit-различия. Это функциональная проверка, а не доказательство лучшего среднего процента.17 не показал завершённой доставки во всех трёх раундах;25 дал ложный PASS чертежа,26/27 сохранили подтверждённые ошибки. Эти роли не продвигаются по номеру версии.

При переключении сохраняются принятые страницы со старой фактической версией проверяющего и все980черновиков. Незавершённые страницы получают новый review21; готовые не извлекаются повторно. Источник, физическая/напечатанная страница, модели, версии и source-bound receipts сохраняются отдельно. Подтверждённые ошибки чертежей остаются поводом для адресного исправления.

Новые большие бенчмарки не запускаются. Критерий завершения —980страниц проходят review без открытых замечаний; JSON и Excel сохраняют происхождение. Профиль фактически запущен:496 принятых результатов и все980 черновиков сохранены с прежними производителями. Первые новые native review21 и отдельная разрешённая blind-проба чертежа27 ещё выполняются. Оценка чертежей для этого рабочего профиля не заявляется.
