# Рабочая связка для завершения всех каталогов

Извлекатель — MiniMax M3.1 Flash Preview с программой 1.4.15. Проверяющий — GLM 5.3 Flash через Coding Endpoint с программой 1.4.30. Управляющая очередь — 1.4.30. Версии создавших JSON и review агентов сохраняются отдельно от координатора и экспортера.

В 1.4.28 устранены противоречивые исходные/финальные количества таблиц, строк и колонок; такой отчёт возвращается проверяющему для разрешения по оригиналу до передачи извлекателю. Очереди чередуют первые проверки и ремонты, а внутри групп — каталоги. Новая очередь уже доставила настоящий native review первой страницы Арматуры. Исправления не ограничены числом попыток; ProviderGate сохраняет адаптацию после 429.

В 1.4.30 числовые подписи фигуры требуют свидетельств отдельно для исходного наблюдения и кандидата. Общий PASS без привязки к виду и измеряемому контуру запрещён. Это контроль полноты проверки; новый процент геометрической точности не установлен. Перепроверенные старые ложные PASS были отклонены без изменения кандидатов, в том числе через настоящий MCP без вызовов моделей.

Полная очередь фактически запущена. При переходе сохранены все 980 черновиков и ровно 500 принятых страниц со старыми фактическими производителями. Незавершённые страницы получают новый review; ранее принятые не объявляются прошедшими 1.4.30. Полная верификация всех каталогов ещё не завершена. При лимитах провайдера очередь сохраняет работу и снижает параллельность.
