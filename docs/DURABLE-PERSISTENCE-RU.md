# Сохранение результатов при перезагрузке

В1.4.25 JSON сохраняется с синхронизацией файла до атомарной замены, затем синхронизируется запись каталога. Журнал инструмента синхронизируется до подтверждения осмотра или сохранения. Ошибка диска возвращается вызывающему агенту; прежний полный JSON остаётся доступным, если сбой произошёл до замены.

Независимые замечания читаются один раз: проверяющий получает те же байты, чей отпечаток фиксируется в журнале. Страница не становится принятой, пока последняя версия замечаний не прочитана. Срок работы очереди применяется и к мгновенным локальным завершениям. Неизменные снимки других каталогов повторно не записываются.

Проверено162 сценариями и настоящим stdioMCP сохранением страницы: редактирование рисунков и финальное сохранение сохранили64 ячейки таблицы и весь остальной JSON. Проверки сбоя записи и замены файла замечаний сначала воспроизвели ошибки, затем прошли. Для тестов порядка очереди задержка диска моделируется отдельно; тесты сохранения и MCP используют реальную запись.

Это проверка механизма сохранения, а не новый замер точности модели. Реальное отключение питания в ходе проверки не выполнялось. Модель, параметры, версия программы и исходные выходные файлы каждого испытания сохраняют свою идентичность; результаты прежних версий не переименовываются в1.4.25.
