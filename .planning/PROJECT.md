# Catalog to JSON

PDF product catalogs become versioned, schema-valid JSON. A native FastAgent skill agent uses tools for AnyDoc, original-page/region Vision and schema-validated JSON file writes. A separate strict reviewer compares against the original; bounded automatic repair handles defects. Only JSON is canonical. Excel/HTML are deterministic exports.

Owner approved a new public repository on 2026-10-11. Defaults use GLM 5.3 Flash in independent histories; the accepted live sample used GLM extraction and MiniMax M3.1 Flash Preview review after subscription availability returned. No manual catalog-value corrections.

Inputs and model results remain private ignored artifacts. First live acceptance uses the provided catalog's page 78, containing rotated headers, merged data cells, two tables and labeled diagrams.

Initial version is a PDF CLI, not a hosted app. Different catalogs use a generic table/text/figure schema; no hardcoded page-78 product data.

Architecture correction: user requires actual tool-using skill agents, packaged as Agent Plugin 1.0; conversational model outputs are not constrained to JSON. Schema validation is a file-tool responsibility.
